# 🏏 CricScore

A responsive cricket scoreboard web application built with vanilla HTML, CSS, and JavaScript — featuring a dynamic dark/light theme toggle and clean, real-time score tracking UI.

## 🔗 Live Demo
[https://hassanmohammed1286-creator.github.io/cricscore/](https://hassanmohammed1286-creator.github.io/cricscore/)

## ✨ Features
- Real-time cricket score display
- Dark/Light theme toggle with custom SVG icons
- Player and team images with country flags
- Fully responsive design
- Clean, modern UI

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)
- GitHub Actions (CI/CD)
- GitHub Pages (Hosting)

## 🚀 Getting Started (Run Locally)

Clone the repository:
```bash
git clone https://github.com/hassanmohammed1286-creator/cricscore.git
cd cricscore
```

Open `index.html` in your browser, or use a live server extension in VS Code.
